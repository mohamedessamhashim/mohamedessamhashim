## 🔬 Selected Projects

### 🧠 GBM-Twin — Post-treatment Glioblastoma Segmentation
3D deep-learning pipeline for automated segmentation of post-treatment glioma sub-regions on multiparametric MRI (BraTS 2024).
- Standardized preprocessing across the cohort: co-registration, resampling, intensity normalization, skull-stripping.
- Vision-only baselines (nnU-Net, Swin-UNETR) with reproducible, containerized inference.
- **Stack:** Python · PyTorch · MONAI · CUDA · NIfTI
- 🔗 *[repository →](https://github.com/mohamedessamhashim)*

### 🩸 IL-6 Transcriptomics in Alzheimer's Disease
Analysis of blood-derived IL-6 mRNA expression as a candidate biomarker for early AD and mild cognitive impairment.
- General linear modeling across **329 participants** from public transcriptomic cohorts (GEO).
- Published as a **medRxiv preprint** (see above).
- **Stack:** R · GEO · GLM
- 🔗 *[repository →](https://github.com/mohamedessamhashim)*

### ⚡ StrokeTriage — Emergency Stroke Decision Support
Web application integrating NIHSS, BE-FAST+, and ASPECTS scoring with AHA/ASA guidelines to support tPA / thrombectomy decisions in the ED.
- **Stack:** Python · Django
- 🔗 *[repository →](https://github.com/mohamedessamhashim)*
